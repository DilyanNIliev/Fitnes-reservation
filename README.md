# 🏋️ Сайт-визитка за личен фитнес треньор

Модерен, адаптивен (mobile-first) едностраничен сайт на български език с **онлайн резервационна
система**. Изграден на чист HTML + CSS + JavaScript — без билд процес, без зависимости.
Готов за качване в **GitHub Pages**.

👉 **Демо:** `https://<твоят-потребител>.github.io/Fitnes-reservation/`

---

## 📐 Дизайн концепция

**Цветова схема:** антрацит `#0B0C0E` + лайм акцент `#D2FF3A`
**Типография:** Oswald (заглавия, bold, uppercase) + Inter (текст)
**Усещане:** много whitespace, енергична диагонална динамика, плавни hover ефекти и reveal
анимации при скрол.

## 🚀 Пускане в GitHub Pages

1. Push-ни кода в репото (вече е в клона `claude/fitness-trainer-website-7khjpu`).
2. В GitHub: **Settings → Pages**.
3. **Source:** `Deploy from a branch`.
4. **Branch:** избери клона и папка `/ (root)` → **Save**.
5. След 1–2 минути сайтът е на `https://<потребител>.github.io/Fitnes-reservation/`.

> Ако искаш да е на `main`, просто merge-ни клона и избери `main` в стъпка 4.

### Локален преглед

```bash
python3 -m http.server 8000
# отвори http://localhost:8000
```

## ✏️ Как да го персонализираш

| Какво | Къде |
|---|---|
| Име, телефон, имейл, адрес | `index.html` — секция „Контакти“, JSON-LD в `<head>`, `CONFIG` в `js/booking.js` |
| Телефон за WhatsApp/Viber | `index.html` — търси `wa.me/359888123456` и `viber://chat?number=` |
| Цени и пакети | `index.html` — секция `#services` + `<select id="package">` |
| Работно време за резервации | `js/booking.js` → `CONFIG.hours` **и** `WORKING_HOURS` в `Code.gs` (0 = неделя … 6 = събота) |
| Цени за календара/таблицата | `js/booking.js` → `PACKAGES` |
| Срок на промоцията | `js/main.js` → променливата `deadline` (по подразбиране: краят на текущия месец) |
| Акцентен цвят | `css/style.css` → `--accent` в `:root` |
| Снимки | замени файловете в `assets/img/` (виж по-долу) |

### Смяна на снимките

Placeholder-ите са SVG. Замени ги с реални снимки (JPG/WebP) и обнови пътищата в `index.html`:

```html
<img class="hero__bg" src="assets/img/hero.webp" alt="…" width="1600" height="900">
```

Препоръчителни размери: hero `1600×900`, портрет `900×1100`, преди/след `800×1000`,
блог `1200×800`. Компресирай ги (напр. с [squoosh.app](https://squoosh.app)) — целѝ под 200 KB.
**Не махай `alt` текстовете и `width`/`height` атрибутите** — те пазят SEO и предотвратяват
„скачането“ на layout-а.

## 📧 Google Calendar — свободни часове и запис на резервациите

Резервациите **не се пазят в браузъра**. Единственият източник на истина е Google Calendar
на треньора, а връзката минава през Google Apps Script web app.

```
Сайтът                              Apps Script                Google
──────────────────────────────────────────────────────────────────────
избор на дата  ──GET ?date=…──────>  doGet()      ──────────>  Calendar
               <──{busySlots:[…]}──               <──заети──
потвърждение   ──POST (JSON)──────>  doPost()     ──────────>  Calendar + Sheets
                                                  ──────────>  имейл до клиента и треньора
```

### Настройка

1. Отвори [script.google.com](https://script.google.com) → **New project**
2. Постави съдържанието на `google-apps-script/Code.gs`
3. Смени горе в файла: `CALENDAR_ID`, `SHEET_ID` (по избор), `TRAINER_EMAIL`, `LOCATION`
4. **Deploy → New deployment → Web app**
   - *Execute as:* **Me**
   - *Who has access:* **Anyone**
5. Копирай генерирания Web App URL в `js/booking.js`:

```js
var GOOGLE_SCRIPT_CONFIG = {
  enabled: true,
  webAppUrl: "https://script.google.com/macros/s/.../exec"
};
```

> ⚠️ **Важно:** списъкът `WORKING_HOURS` в `Code.gs` трябва да съвпада с `CONFIG.hours`
> в `js/booking.js`. Скриптът връща като заети само часове, които са в неговия списък —
> ако сайтът предлага 07:00, а скриптът не го познава, събитие в 07:00 няма да се отрази.

### Как се държи сайтът

- При избор на дата тегли заетите часове на живо и ги показва като недостъпни
- `doPost` проверява за застъпване и отказва двойна резервация
- Ако Календарът не отговори, часовете остават избираеми и се показва бележка,
  че часът ще се потвърди по телефона — формата никога не блокира клиента

## ♿ Достъпност и SEO

- Семантичен HTML (`header`, `nav`, `main`, `section`, `article`, `figure`), йерархия `h1 → h3`
- „Skip to content“ линк, ARIA роли за табовете, календара и модала, видим focus индикатор
- Контраст на текста ≥ 7:1 върху тъмния фон
- `prefers-reduced-motion` изключва анимациите
- Meta description, Open Graph, canonical, `sitemap.xml`, JSON-LD (`HealthAndBeautyBusiness`)
  с адрес, работно време и рейтинг за rich results в Google

## ⚡ Производителност

- Без JS библиотеки и без билд — общо под 150 KB
- SVG изображения (векторни, по ~3 KB), `loading="lazy"` за всичко под fold-а
- Шрифтовете се зареждат с `preconnect` + `display=swap`; ако искаш нула външни заявки,
  махни `<link>` към Google Fonts — системните шрифтове са зададени като fallback
